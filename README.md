## 🔧 Troubleshooting Approach

One of the main goals of this repository is to document **problems encountered during hands-on AWS work**, rather than only documenting successful configurations.

For each troubleshooting exercise, the general approach is:

1. Identify the observed problem.
2. Check the relevant AWS configuration.
3. Verify networking and connectivity.
4. Inspect security group and routing rules.
5. Validate target health and service configuration.
6. Identify the root cause.
7. Apply the fix.
8. Verify the result.
9. Document the lesson learned.

This makes the repository useful as both a learning journal and a future troubleshooting reference.
